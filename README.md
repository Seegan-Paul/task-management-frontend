# Task Management Frontend

This is the frontend of a full-stack **Task Management System**, built using **React.js with Vite**.

## 🔐 Features

- Login using JWT authentication
- Task list with:
  - View all tasks
  - Search by Task ID
  - Filter by Task Status (TODO, IN_PROGRESS, COMPLETED)
- Responsive and simple UI
- Integrated with backend hosted on **Azure App Service**

## 🚀 Tech Stack

- [React.js](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Axios](https://axios-http.com/)
- React Router DOM
